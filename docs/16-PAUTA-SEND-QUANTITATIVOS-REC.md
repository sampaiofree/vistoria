# Pauta SEND — Quantitativos de REC

> **Tipo:** pauta futura de validação técnica. Este documento registra perguntas e
> decisões pendentes com a SEND; não altera as fórmulas atualmente executadas pelo
> catálogo nativo.

## Objetivo da conversa

Confirmar com a SEND como deve ser calculado o peso dos elementos de
recuperação estrutural (REC) cadastrados no sistema.

## Como o sistema funciona hoje

- Cada item REC gera um quantitativo em quilogramas (kg).
- Existem dois modos de informar esse peso:
  - **Cálculo automático:** o sistema recebe as medidas do elemento e calcula o
    peso.
  - **Peso manual:** o inspetor informa o peso total em kg.
- A descrição do item é apenas uma identificação livre, por exemplo: “trecho
  da face sul”. Ela não substitui o peso ou as medidas.

## Elementos com cálculo automático

- Perfil W
- Perfil L
- Perfil U
- Perfil UE
- Chapa lisa
- Barra chata
- Chapa xadrez
- Guarda-corpo
- Escada marinheiro
- Perfil tubular
- Perfil L desigual
- Metalon
- Perfil T

## Elementos com peso informado manualmente

- Ligação parafusada
- Telhas
- Grade de piso

## Pontos importantes sobre as fórmulas

- A fórmula **não é igual para todos os elementos**.
- Perfis, chapas, tubos e metalon têm formatos diferentes; por isso, cada grupo
  usa medidas e fórmula próprias.
- Para os cálculos de aço, o sistema usa hoje a densidade padrão de
  **7.850 kg/m³**.
- Guarda-corpo é calculado com peso padrão de **30 kg por metro**.
- Escada marinheiro é calculada com peso padrão de **60 kg por metro**.
- Os três itens manuais não têm fórmula automática nem peso padrão no sistema.

## Prioridades para a reunião

### Urgente

- Validar as fórmulas e os pesos padrão usados nos elementos REC.
- Definir a regra para Ligação parafusada, Telhas e Grade de piso: peso manual,
  fórmula automática ou tabela de pesos.
- Indicar o documento técnico que aprova cada fórmula e quem deve aprovar
  futuras alterações.

### Importante

- Confirmar se uma mesma avaria pode ter vários itens de quantitativo e se eles
  devem ser somados no total da avaria.
- Definir o arredondamento que deve aparecer na tela e nos relatórios.
- Confirmar se Telhado/Tapamento continuará sem quantitativo ou se deverá medir
  área, quantidade ou peso.
- Revisar se os 16 elementos REC atuais são suficientes e se faltam elementos
  ou informações de medição.

## Perguntas para a SEND

- A densidade padrão de 7.850 kg/m³ deve ser mantida para todos os elementos
  calculados em aço?
- As fórmulas usadas para cada perfil e chapa estão de acordo com o padrão
  técnico da SEND?
- O peso de 30 kg/m para guarda-corpo está correto? Há tipos de guarda-corpo
  que precisam de outro peso?
- O peso de 60 kg/m para escada marinheiro está correto? Ele considera gaiola,
  plataforma e demais acessórios?
- Ligação parafusada, telhas e grade de piso devem continuar com peso manual?
  Se não, qual fórmula ou tabela de peso devemos usar?
- Existe algum outro elemento REC que precisa entrar no catálogo?
- Há limites, arredondamentos ou unidades específicas que devemos aplicar aos
  pesos calculados?

## Decisão esperada

- Validar ou corrigir as fórmulas e pesos padrão.
- Definir quais elementos ficam manuais e quais terão cálculo automático.
- Registrar a fonte técnica aprovada pela SEND para futuras revisões.
